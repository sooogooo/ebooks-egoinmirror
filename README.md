## 🚀 快速开始

### 方法一：一键运行（推荐）

**Windows用户：**
```bash
# 双击运行
run.bat
```

**Linux/Mac用户：**
```bash
# 给脚本执行权限
chmod +x run.sh
# 运行脚本
./run.sh
```

### 方法二：手动安装

#### 1. 环境准备
```bash
# 确保已安装 Python 3.7+
python --version

# 安装依赖
pip install -r requirements.txt
```

#### 2. 本地预览
```bash
# 启动开发服务器
mkdocs serve
```
访问 http://localhost:8000 查看效果

#### 3. 构建站点
```bash
# 构建静态文件
mkdocs build --clean
```
生成的静态文件将在 `site/` 目录中

#### 4. 部署到服务器
将 `site/` 目录中的所有文件上传到您的 Web 服务器即可。

## 🔧 故障排除

### 常见问题解决

1. **插件未安装错误**
   ```bash
   # 如果遇到插件错误，请安装对应插件
   pip install mkdocs-sitemap-plugin
   pip install mkdocs-meta-plugin
   ```

2. **编码问题**
   ```bash
   # Windows用户如遇到编码问题
   chcp 65001
   ```

3. **端口占用**
   ```bash
   # 指定其他端口
   mkdocs serve -a localhost:8080
   ```
